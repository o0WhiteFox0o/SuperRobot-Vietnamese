# Native 3D model replacement: 5600 mark

The same set of access was later extended to ships, landmarks and tracks in world map cutscenes, see [World Map Cutscene Model HD](native-ship-model.md).

## 2026-09-24: Preserve original HD markers

The HD shape is changed from rounded water droplets back to the original shape. The original 5600 is a double quadrangular pyramid with a short top and a long bottom: the square ring at the waist is at Y = 6, and the four corners are (±5, 6, ±5); the upper tip is at Y = 12, and the lower tip is at Y = −12, with a total of 8 faces, solved by two `G_VTX` and eight `TRI1` of the ROM resource.

- **Grid**: generated by [`prepare_native_marker.py`](../../tools/recomp/model5600/prepare_native_marker.py). The method is to translate each side of the bicone inward by 0.5 units, and then do the Minkowski sum with a ball of radius 0.5:
- The 8 faces are still the original planes, and the planes are colored;
- 12 edges become cylindrical surfaces, 6 sharp corners become spherical surfaces, and the normals are continuous;
- The two cusps outward compensate for the amount of fillet indentation, so Y is still −12…12 and X/Z is within ±5;
- A total of 510 vertices, 1,016 triangles, and is a closed surface.
- **Material** (5600 fragment shader `src/host/shaders/HdMarkerPS.hlsl`):
- The background color is changed from orange gold (1.0, 0.57, 0.045) to one close to the original bright yellow (1.0, 0.82, 0.16), and the diffuse reflection is weakened;
- Choose a color between skylight (1.0, 0.96, 0.80) and warm ground (0.55, 0.38, 0.08) according to the reflection direction, and add a horizon highlight band;
- The plane is clearly light and dark according to its direction. When the game rotates it, the highlight strip will sweep across each face and chamfered edge in turn.
- **Real machine** (Episode 8 mini-level world map, HD mode): Golden octahedron with shiny ridges; F6 can still switch back to the original diamond shape.
- Resource packages are regenerated in `build/recomp/native-marker/assets`, and old water drop packages are moved to `assets-waterdrop-20260910`. The model viewer displays "Native HD · 1,016 sides". The original acceptance evidence was recorded for Shuidi and will no longer be displayed if the grid summary does not match.
- The value of profile is still called `model_5600: waterdrop`, but the name is still used, and this edge mark is actually drawn.

The following is the record of the first version (water drop).

The first version on 2026-09-10 replaced the yellow diamonds on the plot map with rounded golden water drops. Mesh, normals, and materials are rendered by the host GPU, and the original game continues to provide position, rotation, camera, and story timing. Use original Japanese ROM. ## Try it out

The **F6** of the unified entrance `scripts/Play SRW64 Native.command` already supports switching between pictures and 5600 models: HD is the native HD mark (water drops before 2026-09-24), and Original restores the original eight-sided rhombus; it can be switched back and forth during the plot. If the profile's `presentation.model_5600` is set to `original`, the original model will also be maintained in HD.

Execute in the warehouse root directory:

```sh
.venv/bin/python tools/recomp/run/play_native.py --native-waterdrop --new-game
```

Select New Game → Female Super Type, and enter the opening of the first episode with the default name. Arrow keys move, Z confirms, X cancels, Enter starts, and Esc closes the window. This entry uses the standalone trial record and archive under `build/recomp/native-marker/play/`; the first run will generate a drop mesh when the resource pack is missing. Use other trial entrances to return to the original version.

The 5600 of the local resource page supports two options: original 8 sides and native water drop 3,968 sides. The page uses the same geometry and continuous normals, and the golden material is approximated by the web page; the lighting in the game is subject to the GPU comparison chart.

## Rendering access

`tools/recomp/toolchain/native_model_hook_patches.py` Apply narrow patch to locked RT64 version via `prepare_rt64.py`:

1. The TRI1 processor of F3DEX2 calls the host identification function. Identifies the current segment 4 as the base address, checks the complete 7,048-byte original 5600 resource, and checks the offset of eight solid triangle commands. Heap address changes do not affect recognition, and dotted rings are not marked.
2. The eight commands of the original body form independent draw calls. The first carries native drawing markers, and the other seven carry suppressed markers. Markers are copied into the immutable Workload with the draw call.
3. When RT64 submits the raster draw, it calls the host renderer and obtains the world transformation, view projection, RSP viewport, scissor and screen scaling from the corresponding Workload. The GPU callback does not read the RDRAM of the latest frame.
4. `src/host/native_marker.cpp` In the same command buffer, use the current scene color/depth attachment in Load/Store mode to draw the floating point grid, following the depth comparison and writing settings of the original draw. Then restore the graphics state of RT64 and continue to draw scenes, avatars, and text.

The drop contains 1,986 vertices, 3,968 triangles, using 32-bit indexing. The CPU uploads the host buffer on startup, without going through the N64 vertex cache or integer vertex format. The local height remains Y = −12…12, and the maximum lateral radius is about 5.5; the dashed ring still uses the original geometry and texture.

Materials are approximated using per-pixel normal interpolation, soft key light, fill light, specular and edge reflections. Currently opaque gold and does not include refractions, dynamic shadows, or real environment reflections. The water droplet is symmetrical about its axis, so even if it inherits the original rotation, the shape will not change significantly like a rhombus.
