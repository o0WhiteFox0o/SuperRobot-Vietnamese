# Update check

2026-10-06. In-game update check for the three desktop platforms (macOS, Windows, Linux/Steam Deck): The game only reads `/latest.json` from the official website, without identification and without downloading; the player will be asked before connecting to the Internet for the first time, and can be turned off in the settings later. Android doesn't do it (`update::supported()` is false, the "About" page only has a link line).

## What to do and what not to do

- Read the `https://srw64.dreamquest.club/latest.json` of the official website (generated by the website `web/src/pages/latest.json.ts`, `schema` is `srw64.latest.v1`), and compare the `version` with the `SRW64_VERSION` of this program.
- The request does not carry any identification (no token, no device information), and there is only one GET.
- No download, no installation: When a new version is available, only the version and date are given, and the button opens the download page (`download.<zh|en|ja>`) and update instructions (`notes.<语言>`) in the corresponding language in the system browser. The installation methods of macOS Signature, Deck, and Windows are different, so only prompts at first.

## HD package version

Starting from 2026-10-07, the HD package has its own version number and is released separately from the application:

- The version number is the same number as the application (the first one is `1.0`, and then the last digit is increased by one by default: `1.1`, `1.2`...; use `--hd-version 2.0` to specify when making major changes), written in the package `hd.json`'s `version`; `hd.json` and others `content_sha256` is the summary (`prepare_hd_bundle.py`) of all files (path + content, except `hd.json`, `NOTICE.txt`) in the package. The HD package can be reproduced: the same material is built twice, and the 6644 files are the same byte by byte.
- `build_release.py` Build HD package every time, compare the summary with `hd.content_sha256` of `web/src/data/release.json` in the built submission: if they are the same, use that version without packaging; if they are different, take the new version number (default last digit plus one, `--hd-version` can be specified), type `Marchwind64-HD-<版本>.zip`, `release.json` There is an extra `publish_hd` (tags `hd-<版本>`, `--latest=false`, released before the application), and another `hd-release-notes.md`. The app's release notes only link to the current HD package's release page.
- After release, `web/scripts/sync-release.mjs` writes `hd` into `release.json` on the official website; `hd` of `/latest.json` gives the version, each language download page (installation page `#hd`), files and check values. Older packages without version numbers (the ones released with the application in 0.3.5) do not appear in `latest.json`.
- The game reads installed packages: `SRW64_ART_PACK` (`hd/art`) next to `hd/hd.json`. The art directory for development and running does not have `hd.json`, so it is not installed. `hd_newer()` (`update_version.hpp`): This will only prompt if the package is installed, the version on the official website is newer, or the installed package does not have a version number; players who have not installed HD will not be prompted.

## Status and files

`update.json` (user directory, the launcher is passed in through `SRW64_UPDATE_STATE`, the same directory as `presentation.json`):

```json
{"schema": "srw64.update-check.v1", "automatic": true, "checked_at": 1791262005, "latest": { …上次读到的 latest.json… }}
```

- `automatic` Default = Not answered yet (will ask in the title).
- When it is on, it will be checked after one day from `checked_at` after startup (when the interface is initialized); no error will be displayed if the automatic check fails, and the last result will be retained. Manual checking ignores the interval and displays the reason for failure.
- Saved `latest` so that the title hint can be displayed even when offline.

15 second timeout for all requests, 1 MB response limit. The interface text keys are in UI_KEYS of `src/srw64_native/profile.py` (`update_*`, `update_hd_*`, `settings_update*`, `about_link_*`, `menu_about`, `menu_check_updates`).
